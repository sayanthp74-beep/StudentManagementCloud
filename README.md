# Student Management System

A web-based student management application built with Python Flask and MySQL.

## Features
- Student registration and login
- Student dashboard
- Faculty login and dashboard
- Attendance management

## Technologies
- Python
- Flask
- MySQL
- HTML and CSS

## Run the Application
1. Install dependencies using `pip install -r requirements.txt`.
2. Configure your MySQL database credentials.
3. Run `python app.py`.
